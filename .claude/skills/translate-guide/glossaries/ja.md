# Japanese Tekken glossary

Terminology for translating tekkendocs character guides into Japanese. Taken from Japanese Tekken
sources, not invented. **Append to this file** whenever a run needs a term that is not here, and
record where it came from.

## Movement

| English | Japanese | Note |
| --- | --- | --- |
| sidestep | 横移動 | abbreviated SS; `SSL` / `SSR` in notation stays as-is |
| sidestep right / left | 右横移動 / 左横移動 | "右横に弱い" = weak to sidestep right |
| sidewalk | 横歩き | |
| backdash | バックステップ | community: バクステ |
| tracking | 追尾性能 / 横への追尾 | ホーミング is the move property (homing move) |
| crouch dash | しゃがみダッシュ | 風神ステップ is the Mishima-specific name, don't use it for others |
| crouch cancel | しゃがみキャンセル | |
| background / foreground | 画面奥 / 画面手前 | |

## Register

です・ます調 written-guide style, like the 攻略 sites below. Keep ASCII `"…"` around commands even
though Japanese text normally uses 「」, since the quotes are parsed. Use 、 between listed commands.
