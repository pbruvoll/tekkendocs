# Korean Tekken glossary

Terminology for translating tekkendocs character guides into Korean. Taken from Korean Tekken
sources, not invented. **Append to this file** whenever a run needs a term that is not here, and
record where it came from.

## Movement

| English | Korean | Note |
| --- | --- | --- |
| sidestep (the quick burst, `2n` / `8n`) | 횡신 | |
| sidewalk (held, `2n2` / `8n8`) | 횡보 | |
| sidestep, generically | 횡이동 | |
| sidestep right / left | 오른쪽 횡이동 / 왼쪽 횡이동 | `SSL` / `SSR` inside combo notation stays as-is |
| tracking | 횡 추적 성능 | idiomatically "횡을 잡는다" — *it catches the sidestep* |
| backdash | 백대시 | |
| crouch dash | 크라우치 대시 | |
| crouch cancel | 크라우치 캔슬 | |

## Register

Written-guide 합니다체, like 철권 교실 or a 나무위키 공략 page — not spoken 반말. Keep the
original's second-person coaching voice where it has one ("연타하지 마십시오").
